# Customer Churn Prediction

## 📌 Project Overview
Customer Churn Prediction is a Machine Learning project that predicts whether a customer is likely to leave a company based on customer demographics, account information, and service usage.

The project demonstrates an end-to-end Machine Learning workflow, including data preprocessing, exploratory data analysis, feature engineering, model training, evaluation, and deployment using Streamlit.

## 🎯 Objective
- Predict customers who are likely to churn.
- Identify important factors influencing customer churn.
- Help businesses take proactive customer retention decisions.
- Build an interactive application for real-time churn prediction.

## 🤖 Machine Learning Models
The project uses classification algorithms such as:

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

Models are compared using appropriate classification evaluation metrics to select the best-performing model.

## 📊 Model Evaluation
The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

For churn prediction, Precision, Recall, and F1-Score are considered important because correctly identifying customers at risk of churn is more useful for business retention strategies.

## 💡 Key Insights
The analysis helps identify customer characteristics and service-related factors associated with higher churn risk.

These insights can help businesses:
- Identify high-risk customers
- Improve customer retention strategies
- Reduce potential revenue loss
- Develop targeted customer offers
- Make data-driven business decisions

## 🚀 Streamlit Application
An interactive Streamlit application was developed where users can enter customer information and receive a churn prediction.

### Prediction Output
- Customer likely to churn
